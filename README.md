# PlanYourDay — Productivity Web App

A responsive productivity web application with task management, Pomodoro timers, and an analytics dashboard to help you track and optimize your time.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | React.js, Vite |
| Language | JavaScript (ES6+) |
| Styling | HTML5, CSS3 |
| Package Manager | npm |

## Features

- **Task Management** — Create tasks with priority levels and categories
- **Completion Tracking** — Mark tasks complete and track progress
- **Pomodoro Timer** — Focused work timer per task (25-min work / 5-min break cycles)
- **Analytics Dashboard** — Visual insights including:
  - Time logged per task
  - Task completion rate
  - Time distribution across categories
- **Responsive Design** — Works seamlessly on desktop and mobile

## Screens

| Screen | Description |
|--------|-------------|
| Task List | Create, edit, delete tasks; set priority & category |
| Timer | Pomodoro timer with start/pause/reset per task |
| Dashboard | Analytics showing time logged, completion rate, distribution |

## How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/ysurendra25/planurday.git
   cd planurday
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the dev server**
   ```bash
   npm run dev
   ```

4. Open the URL shown in terminal (typically `http://localhost:5173`)
